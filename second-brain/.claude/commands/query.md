# Skill: Research Query

Research question: **$ARGUMENTS**

## Step 1: Understand scope
Read `wiki/_index.md` in full.

## Step 2: Identify relevant content
Find the 3-7 most relevant concept articles and 2-5 most relevant summaries.
Check `wiki/queries/` for related previous answers.
Read all identified articles in full.

## Step 3: Follow threads
If articles reference other relevant articles, read those too.

## Step 4: Synthesize

```
# [Short descriptive title]

*Query date: [today's date]*
*Question: [the question as asked]*

## Answer
[Direct, clear answer in 2-3 sentences. Lead with the answer.]

## Analysis
[Detailed analysis with subheadings if needed. Cite evidence.]

## Evidence
[Key facts and data with sources noted]

## Caveats and Uncertainties
[Where evidence is thin, conflicting, or outdated]

## Knowledge Gaps
[What you'd need to give a more complete answer]

## Follow-up Questions
[2-3 questions that naturally arise]

## Sources Used
- [[concepts/article-name]]
- [[summaries/source-name]]
```

## Step 5: Save and index
- Save to `wiki/queries/[YYYY-MM-DD]-[short-slug].md`
- Add to `wiki/_index.md` under `## Queries`

## Step 6: Note enrichment opportunities
If the query revealed insights not yet in concept articles, flag them for the next `/compile` run.
