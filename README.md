# AI-Native Course: Claude Code for Business People

A practical, hands-on course that takes you from zero to building a powerful personal knowledge base using Claude Code.

## Who This Is For

Business professionals who want to leverage AI not just as a chatbot, but as an intelligent collaborator that reads, writes, and manages knowledge on your behalf.

No prior coding experience required. You will learn by doing.
